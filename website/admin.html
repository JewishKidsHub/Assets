🔑 Upload code 🔒 Uploads are locked

Uploading pictures and videos needs a secret upload code. Save it on just this device, or share it with the whole team once so nobody else has to enter it. It's never written into the page itself. Without a code, any upload will say you don't have permission.

📧 Email check Off

When this is on, after signing in each admin has to type a 6-digit code emailed from the Jewish Kids Hub email, so only the real person gets in. The code lasts 10 minutes and "verified" lasts 12 hours on that browser.

🎬 Video storage Off

Send uploaded videos to your own video address (for example videos.jewishkidshub.com) instead of the normal file storage. Pictures and other files keep using the upload code above. Leave blank to keep videos in the normal storage.

🎯 Rules for each upload spot
